# Inciso IV: palavras pouco comuns que um guia oficial manda trocar por
# outra mais conhecida.
# Uma entrada por linha: palavra | sinônimo que o guia dá | fonte.
# Página do arquivo PDF; entre parênteses, a impressa, quando é outra.
# "*" no fim de uma palavra vale por qualquer terminação. Onde o radical
# pegaria outra palavra ("execut*" pega "executivo"; "requisit*",
# "requisito"; "protocol*", "protocolo"; "expedi*", "expediente";
# "consum*", "consumo"), as formas do verbo vêm uma a uma, com a fonte do
# infinitivo. Lista fechada: palavra difícil fora dela passa.
# Fontes:
# - TJRS, Guia de Linguagem Simples (Inovajus, 2022), PDF de 108 páginas,
#   conferido em 10/10/2026: quadro de "palavras complexas com sinônimos
#   mais simples", p. 31 e 32 (32 e 33). Na p. 32 o PDF desalinha as
#   colunas; o par certo é o da ordem das linhas (postular / pedir,
#   solicitar; pugnar / insistir, sustentar; requisitar / solicitar).
# - CAPES, O uso da Linguagem Simples na CAPES (2026), p. 8 (7), item 7
#   "Use palavras comuns", "Dicas de substituições".
# - Anvisa, Guia de Linguagem Simples, 1ª ed., p. 12, item 3 "Prefira
#   palavras conhecidas".
# - SES-DF, Guia para simplificar documentos (2024), p. 9, "Passo 5 Use
#   palavras do cotidiano".
# De fora: "peticionar" (CAPES p. 8; está no léxico do V, com a SES-DF
# p. 10); "requer" e "requerem" (no gov.br, quase sempre "exige", e não
# "pede"); "ensejo" e "postulado" (substantivos de outro sentido); o
# quadro de formas sintéticas do TJRS (p. 20): é de palavras sobrando.
